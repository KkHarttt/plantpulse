
# CLAUDE.md — Правила разработки PlantPulse

## 1. Описание проекта

PlantPulse — программный проект, разработка которого должна выполняться в соответствии с техническим заданием, размещённым в папке docs.

Техническое задание является главным источником требований к функциональности приложения.

Перед реализацией новых функций необходимо ознакомиться с ТЗ.

## 2. Технологический стек

### Клиентская часть (web)
- Next.js
- React
- TypeScript
- ESLint
- App Router
- npm

### Серверная часть (api)
- NestJS
- TypeScript
- Node.js
- npm
- ESM (ES Modules)

### База данных
- PostgreSQL 16
- Docker
- Docker Compose

## 3. Структура проекта

- docs/ — техническое задание и документация.
- web/ — клиентская часть приложения.
- api/ — серверная часть приложения.
- docker-compose.yml — конфигурация Docker и PostgreSQL.
- CLAUDE.md — правила для ИИ-помощника.

## 5. Правила разработки

1. Всегда следовать техническому заданию из папки docs.
2. Не добавлять функции, отсутствующие в ТЗ, без согласования.
3. Сохранять существующую структуру проекта.
4. Использовать TypeScript для клиентской и серверной частей.
5. Не подключать Tailwind CSS.
6. Использовать ESLint для проверки качества кода.
7. Не удалять существующие файлы без необходимости.
8. Не изменять конфигурацию Docker без необходимости.
9. Проверять работоспособность кода после внесения изменений.
10. Не изменять версии зависимостей без необходимости.
11. Не помещать секретные данные непосредственно в исходный код.
12. Перед выполнением масштабных изменений объяснять план действий.

## 6. Работа с Git

- Основная ветка проекта: main.
- Перед внесением изменений проверять состояние Git.
- Использовать понятные сообщения коммитов.
- Не добавлять временные файлы и системные файлы macOS.
- Не удалять историю существующих коммитов.

## 7. Основное правило

Все решения по архитектуре, интерфейсу и функциональности должны соответствовать техническому заданию PlantPulse.

При обнаружении противоречий между ТЗ и предполагаемой реализацией необходимо сначала сообщить об этом и запросить уточнение.
